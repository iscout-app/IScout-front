## 📋 Checklist Antes de Commitar

- [ ] Rode `bun run lint` - Código sem erros
- [ ] Rode `bun run format` - Código formatado
- [ ] Remova `console.log()` de debug
- [ ] Atualize README se necessário
- [ ] Verifique que `.env` NÃO está sendo commitado

## 🔒 Segurança

**NUNCA** commitamos:
- ❌ Senhas ou tokens em `.env`
- ❌ `node_modules/`
- ❌ Arquivos de build
- ❌ Logs com dados sensíveis
- ❌ Configurações locais do IDE

**SEMPRE** commitamos:
- ✅ Código fonte em `src/`
- ✅ Configurações compartilhadas
- ✅ README atualizado
- ✅ `.env.example` (sem valores reais)
